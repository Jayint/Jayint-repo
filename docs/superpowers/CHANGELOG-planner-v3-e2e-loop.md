## Fix: python-shim preflight rejection — live-e2e certify-loop churn (root-cause, TDD) — 2026-07-07
**Observation:** the first LIVE e2e (deepseek-v4-flash/OpenRouter on pallets/flask, base `python:3.10-slim`) never entered the LLM repair loop. Each cycle only: create container → issue the python shim → `Command rejected before execution by sandbox preflight.` → reset → repeat, ~5 min/cycle under `linux/amd64` emulation, doomed to a `max_cycles` FAIL. `ensure_python_shim` (`depgraph_live.py`) issued `command -v python >/dev/null 2>&1 || ln -sf "$(command -v python3)" /usr/local/bin/python` through the MUTATING, preflight-gated `sandbox_execute`; the sandbox's `_get_invalid_compound_setup_prefix` classifies both `||` arms as setup and rejects it as "combines multiple independent setup mutations." The shim is best-effort (swallows exceptions) but a preflight rejection is a `(False, prefix)` RETURN, not an exception, so it silently no-ops — bare `python` stays unresolved and depgraph check_commands (`python -m pip show …`) exit 127, so installed nodes never certify and the drain re-emits the same closure every cycle.
**Why:** the sandbox preflight is an AGENT-facing gate (force the LLM to split compound Actions so each state change is independently recordable/replayable) — the established host-internal bootstrap (`_bootstrap_apt_if_supported`) bypasses it via a direct `container.exec_run`. Routing a host bootstrap through the agent gate was the defect. Minimal on-design fix: make the shim a SINGLE setup Action (which preflight admits) rather than add a second exec path. `ln -sf` is already idempotent, so the `command -v python ||` guard was redundant as well as rejected — verified on `python:3.10-slim`: `python -> python3 -> python3.10` before, `python -> /usr/local/bin/python3` after, `python --version` == 3.10.20 (and it creates the link on a python3-only base).
**What:** `depgraph_live.py::ensure_python_shim` now issues the lone `ln -sf "$(command -v python3)" /usr/local/bin/python`; docstring records why it must stay a single Action. TDD: added `test_ensure_python_shim_command_passes_sandbox_preflight` (builds a `Sandbox.__new__` + `Synthesizer()` — no Docker — and asserts `_get_preflight_rejection_prefix(cmd) == ""`, the exact regression) and tightened `test_ensure_python_shim_emits_idempotent_symlink` to `"||" not in cmd`. Both RED against the old compound (rejection message captured), GREEN after.
**Verification:** `tests/test_depgraph_live_certify.py` 6 passed; `tests/test_sandbox.py tests/test_sandbox_exec_readonly.py` 35 passed; `tests/envstate/` 148 passed — no regression. No other test hardcoded the old compound string. Commit-local, NOT pushed. Live re-run of the flask control e2e pending (this fix unblocks it).
**Philosophy check:** ✅ root-cause not patch — fixes the layering error (host bootstrap must not go through the agent preflight) at its cheapest correct point, matching the existing apt-bootstrap pattern's intent (single/atomic host setup) without proliferating exec paths; regression-locked by a test that runs the REAL preflight, not a reimplementation; idempotence re-proven on the actual target image before trusting the reword.
