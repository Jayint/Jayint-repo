3. Never discard real code path

  

    runtime_ingest.py:124. When the curated table cannot resolve an import to a distribution,
    the observation is deleted — not parked, not flagged. Deleted.
  


def _annotate_or_append(graph, d, owner_node_id=None):
    if d.name is None:
        # Unresolved import: no distribution to graph. Never fabricate a `pkg:None`
        return graph          ← the observation is gone. The graph now renders CLEAN.

    # proposed: there is always something to create, because the node is keyed on the
    # OBSERVATION, not on the RESOLUTION.
    return graph.with_node(error_node(kind="unbound", key=sig(d.evidence), ...))

  

    This is the line that makes a negative verdict impossible. You cannot tell the agent
    "the environment is certified — this is not an environment failure" while you are silently
    deleting the evidence against you. It is also the honest home for the 25 env-var repairs and the
    19% of test failures where summarize() returns nothing at all.

The one-line thesis. A failed check is an observation, not a demand. Today they are
fused — rc != 0 → MISSING → _is_emittable → an install command — and
that fusion is what turns a wrong check into a wrong command. Insert a gap, and the graph gains the one
thing a log structurally cannot do: it can prove a negative.
