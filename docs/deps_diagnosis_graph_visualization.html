How the agent uses it

A pure loop over 4 calls:
g = diagnose(static_evidence) — cold start
g = ingest(g, cmd, output) — append runtime evidence
a = next_action(g) — pick the move
is_ready(g) — honest done-gate
Acting rule: act on the deepest unproven Need reachable via depends_on; pick its highest-trust, non-exhausted/ineffective Provider; prefer a retracts provider (voids a whole subtree). If the frontier is a conflicts_with, the action is relax a pin, not install.
Honesty invariants: a Need is proven only by its own check_command (host-run) — never because a Provider installed, never via --collect-only. A failed Attempt marks its Provider exhausted/ineffective → never re-picked (anti-loop).
