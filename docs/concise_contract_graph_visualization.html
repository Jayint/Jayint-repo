Concise Contract Graph V1

The new graph has only three durable node types: Contract, Blocker, and Attempt. This view intentionally omits WorldModelMap evidence so the contract graph shape is clear.

Graph View

What Changed From The Old V1 Page

Repo artifacts, capabilities, validators, failures, transitions, and revisions are no longer separate contract-graph node types. Most of that belongs in WorldModelMap or command evidence.

Contract: what must become true
Blocker: runtime symptom violating a contract
Attempt: repair action aimed at a contract

Three Edges

depends_on Contract -> Contract. One obligation cannot hold unless another holds.
violates Blocker -> Contract. A runtime symptom proves or suggests the obligation is not true.
addresses Attempt -> Contract. A repair was proposed or executed to make that obligation true.
